# Whiteboard

A responsive, browser-based whiteboard built with vanilla HTML, CSS and JavaScript. No build step or external dependencies are required.

## Run it

Open `index.html` in a browser, or enable GitHub Pages for this repository and publish from the `main` branch (root folder).

## Features

- Pen, highlighter and eraser
- Lines, arrows, rectangles and circles
- Text labels and sticky notes
- Add images from your device
- Colour palette, stroke size and solid/dashed/dotted lines
- Dotted, grid and plain canvas backgrounds
- Undo and redo
- Zoom and pan tools
- Automatic local browser saving
- Export your board as a PNG

Your boards are stored in the browser's local storage on the device where you create them. Export a PNG to keep or share a snapshot.
